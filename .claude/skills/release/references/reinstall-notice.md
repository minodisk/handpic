## Riffle users: reinstall to get this release

Handpic 2.0.0 is a new app that replaces the earlier one (up to 1.10.0,
released as Riffle). **The earlier app does not update to it.** Download the
file for your OS from the assets below and install it:

| OS                   | File                                                                                      |
| -------------------- | ----------------------------------------------------------------------------------------- |
| macOS, Apple Silicon | `Handpic-<version>-macos-arm64.dmg`                                                       |
| macOS, Intel         | `Handpic-<version>-macos-x86_64.dmg`                                                      |
| Windows              | `Handpic-<version>-windows-x64-setup.exe` (or the portable `…-windows-x64.zip`)           |
| Linux                | `Handpic-<version>-linux-x64.tar.gz` with `install.sh` (or `handpic_<version>_amd64.deb`) |

Handpic is not signed by Apple or Microsoft, so the first launch asks for
your permission once (macOS: System Settings → Privacy & Security → Open
Anyway; Windows: SmartScreen's More info → Run anyway). From this version on,
Handpic updates itself.

What comes along:

- **Judgments**: they are in the sidecars next to your RAW files.
- **Settings**: taken over once from the earlier app's settings on the first
  launch; the earlier app's file is only read.
- **The folder index**: a cache, built again as you open folders.

The earlier app is not removed for you; remove it the way you installed it
once you no longer need it. The steps per platform are in the
[install guide](https://github.com/minodisk/handpic/blob/main/docs/humans/usage.md#installing).
