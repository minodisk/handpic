`Latest` now keeps each folder's latest file in first-push order with one write out at a time, and `scan::Eviction` holds its lock across the join, so every listing waits for the eviction. `every_waiter_waits_for_the_eviction` cannot deadlock: the main thread never takes the lock before sending the release, a failed assert drops `release` and so ends the eviction thread, and `is_finished` runs only after both waiters have reported. The docs, CLAUDE.md, todo.md and the plan match the change.
