## Round 1

**Reviewed commit**: `3d6a833ded21d4347beb060c8e525168b64286ee` feat(app): pause the scan's reads while a preview read is in flight

STATUS: NEEDS_FIX

### Findings

1. **[crates/core/src/scan.rs:98, crates/core/src/reader.rs:143]**: The slot and the pause are held across more than the file read, and neither the code nor `learnings.md` says so. `read_preview` ends in `hevc::to_jpeg` for an HDR PQ CR3, which is 65-125 ms of CPU per file (`docs/humans/performance.md:687`), and that decode runs inside `let _slot = slots.acquire(cancel)?` in all three scan sites and inside `preview`'s `_paused`. The plan's design rests on the opposite: "the cap must bound the read alone, so that the CPU work after it runs uncapped" and a pause "spans the read only (never a model run or a decode)". Step 1 is safe on the cap, since the cap equals `scan_threads()`, but two effects follow. `preview` on such a file now stops the scan's reads for the decode as well as the read. And once Step 3 sets a small cap, that cap also limits concurrent HEVC decodes: at a cap of 1 or 2, both sweep candidates, a pass over HDR PQ CR3 files tops out around 10-20 files/s while permits sit idle at the disk. Step 2's sweep runs on ARW folders, so it cannot show this, and `READ_SLOTS` would be fixed without it. Either split the read from the decode so the slot and the pause cover only the bytes (for example a `reader` function returning the undecoded `(arw, bytes, codec)`, with the `to_jpeg` call outside the guard), or, if that is left for later, add it to `learnings.md`'s deferred issues and add an HDR PQ CR3 run to Step 2's done-when, so the cap is not picked blind to it.

### Dismissed

1. Deferred as the finding allows, not fixed in the code. Splitting the read from the decode changes `reader` and all scan sites beyond Step 1's behaviour-neutral scope, and is harmless at Step 1's cap of `scan_threads()`. It is recorded in `learnings.md`'s deferred issues, and an HDR PQ CR3 run was added to Step 2's done-when in `plan.md` so the cap is not picked blind to it.
