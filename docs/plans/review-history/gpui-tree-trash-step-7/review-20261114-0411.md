## Round 1

**Reviewed commit**: `c8841afaeeb84467028cef24b2df0b932d8fd69f` feat(native): add Move to Trash and Delete Permanently with their dialog

### Findings

1. **[crates/native/src/main.rs:982 (`confirm_run`) / main.rs:1502 (`switch_format`)]**: The gate treats the folder as idle whenever `Resync::busy()` is false, but the sidecar format switch re-lists through `relist` without `resync.open()` / `resync.changed()`. That listing and its scan never mark `Resync` busy. A realistic sequence: switch the format, close the settings, right-click, then `Move to Trash…` / `Delete Permanently…` while the re-listing is still under way. `busy` is false, so the run starts at once, after `Writer::flush`, and nothing cancels the scan. Meanwhile the listing's `Scan::prepare` → `reconcile_sidecars` (after `reset_sidecars`) queues `writer.set_now` for the folder's files, which can include the files being trashed or deleted. That can write a fresh `.xmp` / `.dop` next to a RAW that is mid-move or already gone, leaving orphan sidecars. Passes 1 and 2 also read those files concurrently. The learnings note (`the native listing (reconcile, sidecar pass) is as much a race with a move as the scan is`) is exactly this case. Fix: in `switch_format`'s completion, mark the re-listing the same way the other paths do (`this.resync.open(); this.relist(cx);`). Since `relist` returns early while a run is in flight, the run's end re-lists anyway. Alternatively, derive "busy" from a listing or scan actually being held, not only from `Resync`. Add a note to the `docs/agents/native-app.md` gate rule so a future `relist` caller keeps `Resync` in step.
2. **[crates/native/src/main.rs:3350-3357]**: `trash_dialog` was inserted between `mcp_request`'s doc comment and `mcp_request` itself. `trash_dialog` now carries both doc comments ("Answer an MCP companion tool call…" followed by its own), and `mcp_request` has none. Move the two-line `/// Answer an MCP companion tool call from the view, after moving it as the call asks.` back above `fn mcp_request`.

### Fixed
