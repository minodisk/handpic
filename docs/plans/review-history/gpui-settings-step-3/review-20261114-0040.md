### Findings

1. **[crates/native/src/main.rs:454]**: `Change::AiEnabled(on)` writes `aiEnabled` to the store but leaves `this.settings.ai_enabled` at its startup value, while `Change::AutoAdvance` two lines up updates `this.settings.auto_advance`. `settings.rs` documents the field as "Whether AI analysis is on", and `native-app.md` / `learnings.md` say the main view owns the values in memory. After one toggle the field is stale, and the first later reader (for example, the pass 3 gate a later step adds) would get the wrong value. Fix: set `this.settings.ai_enabled = on;` in that arm before the write, the same way the `AutoAdvance` arm does.
