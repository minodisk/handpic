### Findings

1. **[crates/native/src/main.rs:1819 (`menu_dismissed`) / crates/native/src/menu.rs:263 (`Menus::dismiss`)]**: GPUI's `on_mouse_down_out` fires for a press of any button (`div.rs` checks only the capture phase and the hitbox, not `event.button`), but the toggles listen only to `MouseButton::Left`. So a right- or middle-press on the open menu's own button closes the menu and leaves `dismissed = Some((which, at))` without a toggle consuming it. The next left press at the same spot (the mouse not moved, the usual case after a right-click) then matches the stale record in `toggle` and does nothing, so the user has to click twice to reopen. Fix: record the press only when it is a left press, for example by passing `e.button == MouseButton::Left` into `menu_dismissed` and calling a `dismiss` that closes without recording otherwise, or by clearing `dismissed` there for other buttons. Add a `menu.rs` test showing that a non-left dismiss followed by a left toggle at the same position opens the menu.
