### Findings

1. **[mise.toml:136]**: `profile="${1:-release}"` never sees the task argument. mise does not pass extra `mise run` arguments to a multi-line `run` script as positional parameters. It appends them to the script's last line. Reproduced with mise 2026.9.5 (CI pins 2026.9.0) using an identical `shell = "bash -c"` task: `mise run t debug` printed `profile=release`, and the last line ran as `echo "end" debug`. So `mise run native:bundle:macos debug` builds the release profile, lays out `target/release/Handpic.app` and echoes `... debug`. The CI step at `.github/workflows/ci.yml:174` then checks `crates/native/target/debug/Handpic.app`, which does not exist, so the macOS leg fails (after a slow uncached release build). `docs/agents/native-app.md:175` documents the same broken `[profile]` argument. Fix: declare the argument through mise's usage spec, e.g. `usage = 'arg "[profile]" default="release"'`, and read `${usage_profile}` in the script (or use the `{{arg(name="profile", default="release")}}` template). Then run `mise run native:bundle:macos debug` locally (the build step can be stubbed) to confirm that `profile=debug` reaches the script.
