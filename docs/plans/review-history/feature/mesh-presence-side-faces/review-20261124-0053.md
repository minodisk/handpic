### Findings

1. **crates/cli/src/facechoice.rs:225-258 (`frame`'s `judge`) and :287 (`af_rule`)**: `facechoice --check` is there to reproduce the scan's `full_eye_sharp` (`af_rule` vs `scan::extract_analysis(p).full_eye_sharp`, mismatches counted), and `Judged`'s doc says "measured as the scan measures its judged face". After this change, `cue_of` leaves `eye_centers` `None` for an untrusted side-face mesh, so the scan stores no `full_eye_sharp`. `facechoice` still takes the raw `mesh_of` centers and measures a value. Every side face that rule (a) fires on now counts as a `--check` mismatch, which makes the check report regressions that are not there. Fix: in `judge`, apply `eyes::mesh_trusted(face, m.presence)` the way `cue_of` does. With an untrusted mesh, set `centers` (and therefore `full_sharp`) to none instead of falling back to YuNet's landmarks. Also add a `presence` column, or document that the EAR / pose / offset columns stay raw like the `eyes` line's. Either way, `af_rule` has to agree with the scan again.
2. **crates/core/src/scan.rs:175-178 (`Analysis::full_eye_sharp` doc) and :302-305 (`full_eye_sharp` doc)**: both docs still say the value is `None` only "when the cue judged no face, the file has no usable larger JPEG, or on any failure". A judged face whose mesh `eyes::mesh_trusted` turns down now also gives `None` (its `eye_centers` is `None`). The plan asks for docs where "`None` without a mesh" is no longer the whole story to be reworded. Add the untrusted-mesh case to these two docs. Also add it to `extract_analysis`'s doc at :186-188, which says "a mesh failure leaves the face its YuNet eye landmarks". That is still true, but the reader is left to assume an untrusted mesh does the same.
3. **crates/core/src/eyes.rs:876 (`judges_a_face_in_a_real_image`)**: the added `println!("presence {presence:.1}")` is a debug print and asserts nothing. The plan's verification ("a frontal face prints a logit in +15..+25") can be pinned here instead. For example, assert `presence > SIDE_FACE_PRESENCE && presence_judges_eyes(presence)`, or assert a measured range, so that a future crop change that drops the bundled face under a threshold fails the test rather than printing quietly.
