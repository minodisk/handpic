On Windows, the one platform it targets, that expectation will fail. `native-app.md`'s "the emptied `.native` folder goes" reads as if it always happens. Change the manual-check expectation to: `index.sqlite` (and its `-wal` / `-shm`) gone from `.native`, with the folder kept because the old `logs\` is still in it. Add a short note to `native-app.md` (and, if you like, the `move_native_index` doc comment) that on Windows the folder stays because it still holds the old log.
