# Learnings

## Step 1

- A todo item recorded from a manual run should quote the full command line.
  The dropped item left out `--size 1400x900`, a preview-size filter, and so
  read a filtered-out listing as a bug.
- The item spanned 13 lines (heading through the blank line after its TODO
  list); removing exactly that range kept one blank line between the
  neighbouring items.
